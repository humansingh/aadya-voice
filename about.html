About Aadya

A voice access layer, not an authority.

Aadya helps a person ask a public-information question, hear a plain answer, and leave with a source and a next step. It is a prototype built around nineteen sourced records, seven languages, and explicit boundaries about what it cannot decide.

7 supported languagesEnglish, Hindi, Marathi, Tamil, Telugu, Kannada and Malayalam. Five are newly added and not yet native-speaker reviewed.
19 sourced recordsThirteen opportunities and six official directories are available through the same repository.
6 protected API routesEvery provider request requires a Firebase identity, including automatic guest identities.
What we are building

Reduce the cost of being confused.

A useful answer is not simply generated text. It begins with what the speech system heard, stays within the evidence retrieved, names what varies by state, and produces an artifact that survives copying or forwarding.

The product does not determine eligibility or represent the government. The official source and office remain the final authority. Aadya’s job is to help someone arrive better informed and better prepared.

System architecture

One voice turn, end to end.

Solid connectors are required in a normal turn. Dashed borders and connectors mark optional account, worker or history behavior. Arrowheads show data direction; gold dots mark hand-offs between system boundaries.

ClientStatic HTML + browser APIs

Boundaries that matter

What the diagram should make obvious.

The model is not the source.

Retrieval provides the scheme record first. The answer model must return structured output grounded in that evidence, with a visible caveat.

Guest does not mean unauthenticated.

The first visit creates an anonymous Firebase identity. It unlocks the microphone without a signup wall while keeping every API endpoint protected.

Optional data is visibly optional.

Private questions skip history; worker cases appear only for signed-in worker accounts; account creation is never required to ask.

Five of Aadya's seven supported languages, Marathi, Tamil, Telugu, Kannada and Malayalam, were added recently.
